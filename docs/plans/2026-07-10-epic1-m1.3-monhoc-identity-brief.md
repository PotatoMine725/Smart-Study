## Goal

Give `MonHoc` a **semantic identity** (not just its `Guid` PK) so the app treats "Toán", "toán ", and

## The one decision that IS the milestone — normalization

Everything keys off "normalized `TenMonHoc`". Define it **once**, consciously, and route **every** site
through the identical function. Drift between sites = dedup that half-works.

**`Normalize(name)` = NFC-normalize → trim → collapse internal whitespace runs to a single space →
invariant-culture lowercase. PRESERVE diacritics.**

- **NFC** is non-negotiable — this is a Vietnamese app; precomposed vs decomposed diacritics (`"Toán"`
  typed two ways) will not compare equal without it. Use `name.Normalize(NormalizationForm.FormC)`.
- **Preserve diacritics** *(owner-approved, locked 2026-07-10)* — `"Toán" == "toán "` but
  **`"Toán" != "Toan"`**. Do not strip accents; "Toán" and "Toan" are different subjects.
- Put it in **one** place: `Models/MonHocIdentity.cs` (static `Normalize(string)` + an
  `IEqualityComparer<MonHoc>` / `StringComparer`-style helper), or a computed `MonHoc.NormalizedName`
  property. Null/empty-safe.

## Non-goals (do not creep)

- **No DB unique constraint** on `(MaHocKy, normalized TenMonHoc)` — the alpha DB holds real duplicate
  data today; a constraint would break `EnsureCreated`/existing rows. Consolidate, don't reject.
- **No cross-device identity-merge / no touching sync metadata semantics** — that's Epic 2. `Rev` stays a
  local counter; you are not merging by identity across devices.
- Not generalizing identity to `HocKy`/`StudyTask`/etc.

## Discriminating test (this is M1.3's accept/refine signal — not optional)

M1.3 collides with M1.2's tombstone-reconcile: `LayDanhSachHocKyAsync` merges tasks across clones into a
representative, and the losing clone gets **tombstoned** on the next `LuuHocKyAsync`. Widening the dedup
key raw→normalized merges **more** clones and migrates **more** tasks across `MonHoc` identities. Prove it
doesn't drop or PK-collide:

> **Integration test:** seed two `MonHoc` rows differing **only** by case/whitespace
> (`"Toán"` / `"toán "`), each with a **distinct** `StudyTask` → `LayDanhSachHocKyAsync` (load) →
> `LuuHocKyAsync` (save) → reload → **assert: exactly one subject; both tasks present; the losing clone
> reads back `IsDeleted == true`; no task lost; no `UNIQUE`/PK exception.**

If that test throws or drops a task, the `MonHoc`/task reconcile needs the **same Guid-diff treatment M1.2
gave `HocKy`** (reconcile-in-place, not remove-then-recreate) before M1.3 can be accepted. Flag it rather
than papering over it.
